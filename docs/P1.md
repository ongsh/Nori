## 可复现验证

```sh
python -m unittest discover -s tests -v
python -m compileall -q nori tests
python -m nori demo /tmp/nori-demo-unique-name
```

测试包含：未批准、批准内容被改、重复/冲突命令、旧修订、假完成、前置未验收、重复启动、过期运行结果、准备窗口崩溃、启动后回执前崩溃、仍在运行的恢复、身份不符、暂停未确认退出、验收前文件变化、验收后变化和下游失效、范围越界、次数上限、不同控制目录同时控制同工作副本、损坏/缺失主状态、磁盘写入故障、视图失败、无效 UTF-8、循环/缺覆盖/越界路径、符号链接，以及进程内并发调用。

进程强杀测试使用真实子进程和 `SIGKILL`，分别在主状态原子替换之前和之后终止。前者重新读取旧完整状态，后者读取新完整状态。它验证软件进程中断边界，不代替断电/硬件故障测试。

## 模拟与真实能力的分界

两份文本的精确比较只证明控制流程能阻止这一明确反例，不能证明能发现任意业务代码缺漏。真实工具接入之前还需验证官方调用、取消及子进程、身份/权限、实际宿主、范围执行边界和真正的业务验收器。

P1 保留完整历史及每次运行验收，但不做无边界历史压缩或大型文件优化。状态和模拟回执必须位于可信本机位置；不能把不可信输入当作控制命令、状态文件或退出证明。
