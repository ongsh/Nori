# 可操作脑图原型

运行 `nori` 后先看到脑图项目列表。打开「Nori 自我迭代」，左边操作脑图，右边编辑选中节点。

- 点击节点：父节点列出可点击的子项；叶节点展示目标、负责人、进度、自报和验收字段。
- 「子节点」「同级」会加入新的节点，可继续向下拆分。改名与编辑后点击保存。
- 删除会先确认整个子树，根节点不能删除。当前没有撤销栈。
- 节点可折叠；拖动画布空白处平移，使用加减缩放、「适配」复位。
- 「预览固定拆分建议」只是原型模板，不调用模型。确认后才将建议变为子节点，不覆盖已有子节点。
- Agent 自报与独立验收分别保存。自报100%不会自动变成验收通过；所有这些字段明确为模拟记录，不改变正式执行内核。

编辑保存在应用数据目录的 `.prototypes` 中，与原有需求草稿和正式工作流状态隔离。两个窗口同时编辑时，旧版本操作会被拒绝并要求刷新，避免静默覆盖。

层级不是固定三层。为避免意外资源耗尽，目前每图最多2000节点、最多100个原型项目，标题200字符、其他文本字段10000字符。这是可交互产品原型，不是真实自动拆分、Agent派单或Nori自我修改。
