# 外部讨论与需求导入

Nori 不提供内置 AI 对话。点击“发起需求”，复制完整的中文角色提示词，在自行选择的外部 AI 或讨论工具中说明想法。提示词指导对方澄清目标、流程、边界和可观察的验收条件；用户确认内容后，再导出标准 JSON。Nori 不会替用户向外部服务发送内容。

1. 复制角色提示词。浏览器拒绝剪贴板时，全文会被选中，可按 Ctrl+C / ⌘C 手动复制。
2. 把外部讨论确认后的 JSON 粘贴进 Nori，或选择本地 JSON 文件。不接受 Markdown 代码围栏。
3. 点击“校验并预览”，查看目标、约束、不在范围内的内容、待澄清问题、需求树和每个节点的原始验收条件。预览只读，不保存。
4. 点击“确认导入需求脑图（不执行）”才会保存。取消不写入数据；修改输入会使旧预览失效，必须重新校验。重复导入同一标准内容不会创建重复脑图。

## 标准 JSON v1

顶层字段必须且只能是：

- `schema_version`：整数 `1`。
- `title`：非空标题。
- `original_request`：用户原始需求原文。
- `goal`：目标说明。
- `constraints`、`out_of_scope`、`open_questions`：字符串数组。
- `nodes`：节点数组。每个节点必须且只能有 `id`、`parent_id`、`title`、`description`、`acceptance_criteria`。最后一个字段为字符串数组。

`id` 唯一；只有一个节点的 `parent_id` 为 `null`，其他节点必须引用存在的父节点。必须构成连通、无环的单根树。父子关系表示需求分解，不表示执行顺序或依赖。UI 的完整提示词和标准示例提供可直接复制的内容，不需要用户手写 JSON。

输入上限：UTF-8 JSON 1 MiB，2000 个节点，标题 200 字符，正文 10000 字符，单个字符串数组 200 项。重复键、未知字段、错误类型、断开的节点和环会被拒绝。

## 导入后的边界

- 导入的是“未批准、未执行”的需求脑图，不是可运行计划。不启动 Agent，不调用工具，不生成内核执行项目。
- 节点名称、说明和层级可以继续编辑。原始 JSON、原始需求和验收条件单独保留、只读展示；本地编辑不覆盖导入原文。
- 导入脑图不提供模拟自报或模拟验收下拉框，避免把要求当成已完成的证据。
- 需求中的路径、命令或工具名称只按文字展示，不会被解释或执行。
- 旧需求草稿继续只读查看。原来的手工脑图和独立模拟执行示例仍可使用；示例不代表任意导入需求已经可以执行。

## 测试

`python -m unittest tests.test_web -q` 包含模板读取、权限检查、非法输入、只读预览、取消、不确认拒绝、摘要冲突、确认导入、重复提交和重新读取；断言不生成内核项目。

`scripts/test_browser.py` 的合成浏览器流程覆盖剪贴板回退、粘贴/文件、无效输入、取消、修改后预览失效、只读原文、确认、刷新与重复导入。浏览器测试需在允许启动 Chromium 的环境运行；不绕过本机浏览器启动限制。
